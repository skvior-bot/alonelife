## 项目是什么

Godot 4.7.2 的 2D 游戏，SLG 模拟经营 + Gal 剧情驱动。

**外层《独居生活》**：刚毕业的男主独自租房，100 天内试着做完一款游戏，过程中可能认识三位同伴。
**内层《孤独之旅》**：他做出来的那款游戏，一个静止的世界。

核心主题：

> **从孤独到不孤独。**
> **世界因为我来过，而和从前有一点不同。**

---

## 当前能玩到什么

Godot 4.7.2 打开工程**无报错**，可以：启动 → 取名（字符选择器）→ 六个地点活动 → 点物体展开事件 → 四格结算器 → 开发/娱乐/吃饭/打工/买设备 → 主动相遇 → 存读档。

**还没做**：作品图鉴界面、手机界面、工作台图层、招募邀约 UI、12 条事件对白演出、第 7 天回望演出、雨天/周几判定、直播发视频。

## 两条不能违反的规则

1. **改数值前先改 `tools/sim.py` 的 CFG 跑一遍**，确认结果再同步 `data/game_data.json`。
2. **核心设计（数值/规则/结构/定论）修改前必须经作者同意**。详见 `CLAUDE.md`「一之二」节。
